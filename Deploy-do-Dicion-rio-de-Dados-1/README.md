# 🗄️ Dicionário de Dados — Sistema de Gerenciamento para Salão de Beleza

Projeto acadêmico de **Modelagem de Banco de Dados**, desenvolvido para estruturar e documentar o banco de dados de um sistema de gerenciamento para o salão **Fátima Aparecida de Lima Cabeleireira**.

O projeto apresenta um dicionário de dados interativo, documentando tabelas, atributos, tipos de dados, restrições, relacionamentos, regras de negócio e classificação de informações conforme a LGPD.

## 🎯 Objetivo

Desenvolver uma estrutura de banco de dados capaz de apoiar as operações administrativas, financeiras e operacionais de um salão de beleza, garantindo organização, integridade, segurança e rastreabilidade das informações.

## ⚙️ Tecnologias Utilizadas

- **HTML5** — Estrutura da aplicação web.
- **CSS3** — Estilização e layout responsivo.
- **JavaScript** — Renderização dinâmica do dicionário, filtros e interatividade.
- **MySQL 8.0** — Tecnologia de banco de dados utilizada na modelagem.
- **InnoDB** — Mecanismo de armazenamento.
- **Panzoom** — Visualização interativa do Diagrama Entidade-Relacionamento (DER).

## 🚀 Funcionalidades

- 📚 **Dicionário de Dados Interativo:** documentação detalhada das tabelas e atributos do banco.
- 🔎 **Pesquisa e Filtragem:** busca por nomes de tabelas ou colunas.
- 🧩 **Diagrama Entidade-Relacionamento:** visualização do DER com zoom e movimentação.
- 📄 **Documentação Técnica:** download da especificação de requisitos e regras de negócio em PDF.
- 🌙 **Modo Escuro:** alternância entre temas claro e escuro.
- 📋 **Documentação de Restrições:** identificação de chaves primárias, estrangeiras, valores padrão e regras de validação.
- 🔐 **Controle de Acesso (RBAC):** documentação de permissões conforme os perfis de usuário.
- 🛡️ **Classificação LGPD:** identificação e classificação dos dados pessoais e sensíveis.

## 🗂️ Organização do Banco de Dados

O projeto contempla diferentes áreas de gerenciamento:

- Cadastro de clientes e fichas capilares.
- Registro de alergias e restrições.
- Controle de usuários e perfis de acesso.
- Catálogo de serviços e histórico de preços.
- Cadastro de produtos e controle de estoque.
- Agendamentos e atendimentos.
- Pagamentos, despesas e fechamento de caixa.
- Auditoria e rastreabilidade das operações.

A modelagem considera a **Terceira Forma Normal (3FN)**, buscando reduzir redundâncias e manter a consistência dos dados.

## 🧠 Conceitos Aplicados

- Modelagem Entidade-Relacionamento (MER).
- Diagrama Entidade-Relacionamento (DER).
- Modelo Relacional.
- Normalização de dados até a 3FN.
- Chaves primárias e estrangeiras.
- Integridade referencial.
- Restrições e validações de dados.
- Controle de acesso baseado em papéis (RBAC).
- Governança e qualidade de dados.
- Proteção de dados pessoais conforme a LGPD.
