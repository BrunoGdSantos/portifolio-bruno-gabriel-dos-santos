# 🎬 Páginas HTML

## 📝 Descrição do Projeto

Este projeto consiste em um site informativo sobre a história dos videogames, apresentando a evolução dos jogos eletrônicos desde os primeiros experimentos até os consoles modernos.

O objetivo principal é proporcionar aos visitantes uma experiência de navegação organizada e acessível, permitindo explorar diferentes conteúdos relacionados à história, aos consoles, às curiosidades e ao universo dos videogames.

Desenvolvido como parte de uma atividade acadêmica, o projeto utiliza páginas HTML independentes para organizar as informações, com recursos visuais, imagens, navegação entre páginas e componentes interativos.

## 🚀 Tecnologias Utilizadas

- **Linguagens:** HTML5 e CSS3
- **Framework:** Bootstrap 5.3.3
- **Ferramentas:** Visual Studio Code e GitHub
- **Recursos:** Navbar responsiva, carrossel de imagens, cards e layouts com Grid Bootstrap.

## 📊 Resultados e Aprendizados

O projeto resultou em um site multipágina com conteúdo organizado e navegação funcional entre diferentes seções.

- **Organização de conteúdo:** Aprendizado na estruturação de páginas HTML independentes e organização semântica dos elementos.
- **Responsividade:** Aplicação do Bootstrap para adaptação do layout a diferentes tamanhos de tela.
- **Navegação:** Desenvolvimento de menu de navegação e links entre páginas.
- **Componentes visuais:** Utilização de carrossel, imagens, cards e recursos de estilização para melhorar a experiência do usuário.
- **Desenvolvimento Front-End:** Prática de integração entre HTML, CSS e Bootstrap na construção de uma aplicação web estática.

## 🧠 Declaração de Uso Ético da IA

Este projeto pode utilizar ferramentas de inteligência artificial, como ChatGPT ou GitHub Copilot, como suporte ao desenvolvimento, incluindo auxílio na compreensão de conceitos, sugestões de estruturação HTML e CSS e identificação de possíveis melhorias no código.

As sugestões geradas por inteligência artificial devem ser revisadas, testadas e compreendidas antes de sua utilização, mantendo a responsabilidade dos desenvolvedores sobre a autoria, integridade e funcionamento final da aplicação.
