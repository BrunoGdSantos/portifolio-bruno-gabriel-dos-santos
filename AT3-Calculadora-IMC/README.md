# 🧮 Calculadora de IMC

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma **Calculadora de Índice de Massa Corporal (IMC)**, utilizando HTML, Bootstrap e JavaScript.

A aplicação permite que o usuário informe seu peso e altura, calcule seu IMC e visualize sua classificação de acordo com os parâmetros de referência para adultos.

## 🚀 Funcionalidades

- Entrada de peso em quilogramas.
- Entrada de altura em metros.
- Cálculo automático do IMC.
- Exibição do resultado com duas casas decimais.
- Classificação do IMC conforme as categorias estabelecidas.
- Mensagens de validação para valores inválidos.
- Apresentação de uma tabela com as classificações do IMC.
- Interface responsiva utilizando Bootstrap.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação da página.
- **Bootstrap 5.3.3:** Estilização dos componentes e responsividade.
- **JavaScript:** Implementação da lógica de cálculo e classificação do IMC.

## 📊 Fórmula Utilizada

O cálculo do Índice de Massa Corporal é realizado através da seguinte fórmula:

```text
IMC = Peso / (Altura × Altura)
```

## 📋 Classificações do IMC

| IMC | Classificação |
|---|---|
| Menor que 18,5 | Baixo peso |
| 18,5 a 24,9 | Peso normal |
| 25 a 29,9 | Sobrepeso |
| 30 a 34,9 | Obesidade grau I |
| 35 a 39,9 | Obesidade grau II |
| 40 ou mais | Obesidade grau III |

## 💻 Como Executar

1. Faça o download ou clone o repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Informe seu peso e altura.
4. Clique no botão **Calcular**.
5. Visualize o resultado e sua classificação.
