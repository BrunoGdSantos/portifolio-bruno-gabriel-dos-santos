# 🧮 Calculadora de IMC

## 📝 Descrição do Projeto

Este projeto consiste no desenvolvimento de uma Calculadora de Índice de Massa Corporal (IMC), permitindo que o usuário informe seu peso e altura para obter o cálculo do IMC e sua respectiva classificação.

A aplicação foi desenvolvida como uma atividade acadêmica de Front-End, com o objetivo de praticar conceitos fundamentais de HTML, JavaScript e utilização do framework Bootstrap.

O sistema apresenta uma interface simples, organizada e responsiva, proporcionando uma experiência intuitiva para o preenchimento dos dados e visualização dos resultados.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação e organização do conteúdo.
- **JavaScript:** Implementação da lógica de cálculo e classificação do IMC.
- **Bootstrap 5.3.3:** Estilização da interface e componentes responsivos.
- **CSS:** Estilização por meio das classes disponibilizadas pelo Bootstrap.

## ⚙️ Funcionalidades

- Entrada de peso em quilogramas.
- Entrada de altura em metros.
- Cálculo automático do Índice de Massa Corporal.
- Validação dos valores informados.
- Classificação do resultado conforme as faixas de IMC para adultos.
- Exibição do resultado com alertas visuais diferenciados.
- Tabela informativa com as classificações de IMC.

## 📊 Classificações do IMC

| IMC | Classificação |
|---|---|
| Menor que 18,5 | Baixo peso |
| 18,5 a 24,9 | Peso normal |
| 25 a 29,9 | Sobrepeso |
| 30 a 34,9 | Obesidade grau I |
| 35 a 39,9 | Obesidade grau II |
| 40 ou mais | Obesidade grau III |
