# 🎬 Páginas HTML
## 📝 Descrição do Projeto
Este projeto consiste em um Calculador automático de IMC, o usuario coloca seu peso e altura, e o sistema calcula automaticamente o IMC  e diz se é saudável ou não.
Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End
Para Web (2026.2)**, o sistema processa a altura e peso e calcula o IMC.
## 🚀 Tecnologias Utilizadas
* **Linguagem:** HTML5, CSS e JavaScript
* **Bibliotecas:** Bootstrap
## 📊 Resultados e Aprendizados
O projeto alcançou resultados sólidos em ambiente de teste, todos os cálculos estavam certos e seguindo as formulas programadas, aprendi a usar JavaScript.
