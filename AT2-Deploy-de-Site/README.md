# 🔭 Telescópio Espacial James Webb

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de um site informativo sobre o **Telescópio Espacial James Webb (JWST)**, apresentando sua história, missão, descobertas científicas, imagens astronômicas e características técnicas.

O objetivo é aplicar conhecimentos de desenvolvimento web na criação de um site organizado, interativo e informativo, explorando conteúdos relacionados à astronomia e à exploração espacial.

## 🚀 Funcionalidades

- **Página Inicial:** Apresentação do Telescópio Espacial James Webb.
- **Sobre:** Informações sobre a história, missão, lançamento e localização do telescópio.
- **Descobertas:** Exibição de descobertas científicas realizadas pelo observatório.
- **Galeria:** Coleção de imagens astronômicas capturadas pelo James Webb.
- **Comparação:** Comparativo técnico entre os telescópios James Webb e Hubble.
- **Ampliação de Imagens:** Sistema de modal interativo para visualizar imagens em maior resolução.
- **Navegação:** Menu para acessar todas as páginas do projeto.

## 🌌 Conteúdos Abordados

- História e desenvolvimento do Telescópio James Webb.
- Lançamento e localização no ponto de Lagrange L2.
- Descobertas sobre galáxias primitivas e exoplanetas.
- Observações de nebulosas e estruturas cósmicas.
- Diferenças entre os telescópios James Webb e Hubble.
