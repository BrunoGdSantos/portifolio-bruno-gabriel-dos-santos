# 🎬 Páginas HTML
## 📝 Descrição do Projeto
Este projeto consiste em em um site que conta curiosidades e descobertas do telescopio espacial James-Webb
Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End
Para Web (2026.2)**, o sistema mostra imagens, curiosidades e possui 5 sites linkados um com os outros em uma navbar.
## 🚀 Tecnologias Utilizadas
* **Linguagem:** HTML5, CSS e JavaScript
* **Bibliotecas:** Bootstrap
* **Ferramentas:** VSCode
## 📊 Resultados e Aprendizados
O projeto foi um sucesso e demonstrou que linkar paginas numa navbar é fácil e acessivel, aprendi muitas coisas sobre HTML durante o desenvolvimento do projeto.
