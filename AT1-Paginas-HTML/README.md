# 🎬 Telescópio Espacial James Webb

## 📝 Descrição do Projeto

Este projeto consiste em um site informativo sobre o Telescópio Espacial James Webb (JWST), apresentando sua história, características tecnológicas, descobertas científicas e imagens impressionantes do universo.

O objetivo principal é proporcionar uma experiência de navegação organizada e visualmente atrativa, permitindo que os visitantes conheçam a importância do telescópio para a astronomia moderna e compreendam suas contribuições para a exploração espacial.

Desenvolvido como uma atividade acadêmica de Front-End, o projeto possui múltiplas páginas HTML que abordam diferentes aspectos da missão, incluindo sua origem, lançamento, funcionamento, descobertas científicas e comparação com o telescópio Hubble.

## 🚀 Tecnologias Utilizadas

- **Linguagens:** HTML5, CSS3 e JavaScript
- **Ferramentas:** Visual Studio Code e GitHub
- **Estilização:** CSS personalizado, Flexbox, layouts Grid e variáveis CSS
- **Tipografia:** Google Fonts (Inter)
- **Recursos:** Modal interativo para ampliação de imagens, navegação entre páginas e efeitos visuais.

## 📚 Estrutura do Projeto

- **index.html:** Página inicial com apresentação do telescópio.
- **sobre.html:** Informações sobre história, lançamento e localização orbital.
- **descobertas.html:** Principais descobertas científicas realizadas pelo James Webb.
- **galeria.html:** Galeria de imagens astronômicas com recurso de ampliação.
- **comparacao.html:** Comparação entre os telescópios James Webb e Hubble.
- **css/style.css:** Arquivo responsável pela identidade visual e estilização do site.
- **image/:** Diretório contendo imagens utilizadas nas páginas.

## 📊 Resultados e Aprendizados

O projeto resultou em um site multipágina com identidade visual própria, navegação funcional e recursos interativos para melhorar a experiência do usuário.

- **Organização de conteúdo:** Desenvolvimento de páginas independentes para apresentar informações sobre o telescópio.
- **Design responsivo:** Aplicação de Flexbox, layouts flexíveis e técnicas de CSS para adaptação a diferentes dispositivos.
- **Interatividade:** Implementação de um modal com JavaScript para ampliar imagens, incluindo carregamento de imagens, fechamento por botão e tecla Escape.
- **Identidade visual:** Criação de uma interface moderna com tema escuro, transparências, efeitos de desfoque e detalhes em tons dourados.
- **Navegação:** Desenvolvimento de menu fixo com indicação da página ativa.
- **Conhecimento científico:** Exploração de informações sobre a missão James Webb, suas descobertas e diferenças em relação ao Hubble.

## 🧠 Declaração de Uso Ético da IA

Este projeto foi desenvolvido sem a utilização de ferramentas de inteligência artificial. Todo o processo de criação, implementação e desenvolvimento do código foi realizado manualmente, utilizando conhecimentos adquiridos durante os estudos de HTML, CSS e JavaScript.
