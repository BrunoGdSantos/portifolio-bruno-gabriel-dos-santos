# 🎬 Páginas HTML

## 📝 Descrição do Projeto

Este projeto consiste em um site informativo e interativo sobre o mercado de tecnologia para desenvolvedores juniores, abordando a promessa dos bootcamps de transição de carreira em seis meses e a realidade de saturação do mercado de trabalho.

O objetivo principal é analisar criticamente as dificuldades enfrentadas por estudantes e profissionais iniciantes, explorando temas como expectativas de empregabilidade, comparação social, impactos psicológicos e a discrepância entre formação e demanda por profissionais.

Desenvolvido como parte da avaliação de Front-End & Copilotagem com IA, o projeto apresenta conteúdos informativos, visualizações de dados e uma ferramenta interativa de autoavaliação, permitindo que os usuários compreendam melhor os desafios da entrada no mercado de tecnologia.

## 🚀 Tecnologias Utilizadas

- **Linguagens:** HTML5, CSS3 e JavaScript
- **Bibliotecas:** Bootstrap 5 e Chart.js
- **Ferramentas:** Visual Studio Code e GitHub
- **Recursos:** Gráficos interativos, questionário diagnóstico, tema dinâmico e layouts responsivos.
- **Dados:** Referências à Brasscom e ao INEP para visualização de informações sobre formação e demanda profissional.

## 📊 Resultados e Aprendizados

O projeto resultou em um site multipágina que combina conteúdo crítico, visualização de dados e funcionalidades interativas.

- **Visualização de Dados:** Desenvolvimento de gráficos interativos para representar a relação entre formação profissional e demanda do mercado.
- **Interatividade:** Implementação de um questionário diagnóstico para avaliar o perfil e os hábitos de estudo dos usuários.
- **Desenvolvimento Front-End:** Aplicação de HTML semântico, CSS3 e JavaScript Vanilla na construção de páginas e funcionalidades.
- **Responsividade:** Utilização do Bootstrap 5 para adaptação do layout a diferentes dispositivos.
- **Experiência do Usuário:** Implementação de tema dinâmico, microinterações e navegação entre páginas.
- **Pensamento Crítico:** Análise dos desafios do mercado de tecnologia, da promessa de empregabilidade rápida e dos impactos psicológicos associados à comparação profissional.

## 🧠 Declaração de Uso Ético da IA

Este projeto utilizou inteligência artificial como ferramenta de suporte tecnológico durante o desenvolvimento, incluindo auxílio na estruturação do código HTML, sugestões de estilização CSS, implementação de funcionalidades JavaScript e apoio na identificação e correção de problemas.

O uso da inteligência artificial foi acompanhado de revisão e validação das sugestões, mantendo a responsabilidade dos desenvolvedores pela compreensão, integridade e funcionamento final da aplicação.

A transparência sobre o uso de IA e as referências utilizadas no projeto são apresentadas na documentação correspondente, incluindo o arquivo AUDITORIA_IA.md.
